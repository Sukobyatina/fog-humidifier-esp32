# Fog Humidifier — увлажнитель туманом высокого давления на ESP32-S3

Домашний увлажнитель воздуха: насос высокого давления (70 бар) распыляет осмосную воду через форсунки 0,08 мм, а контроллер на ESP32-S3 с ESPHome держит заданную влажность и защищает систему. Интеграция — Home Assistant.

> ⚠️ В системе есть сеть 220 В и вода под давлением 70 бар. Повторяйте на свой риск: УЗО 30 мА, предохранительный клапан и проверка по разделу 7 ТЗ обязательны.

## Что умеет

- Импульсный гигростат с гистерезисом по датчику влажности из Home Assistant.
- Пуск насоса на открытый дренаж с плавным разгоном ШИМ и сброс давления после каждой остановки.
- Защиты: сухой ход с ожиданием воды, перегрев и обрыв датчика температуры, риск замерзания, watchdog серии, залипший датчик влажности, жёсткий предел влажности.
- Промывка трассы от застоя (анти-легионелла) — вручную или автоматически после простоя.
- Телеметрия ресурса: моточасы, ТО, фильтры, пуски, расход воды.
- Статус встроенным RGB-светодиодом и кнопка «Стоп / Сброс» на щитке.
- Работает автономно: потеря Wi-Fi или HA не перезагружает плату и не оставляет насос под давлением.

## Оборудование

| Обозначение | Компонент |
| --- | --- |
| A1 | YD-ESP32-S3 N16R8 (VCC-GND Studio) |
| A2 | MOSFET-модуль XY-MOS → насос |
| A4 | SSR-модуль G3MB-202P (вход с транзистором) → клапан сброса |
| A5 | понижающий преобразователь LM2596S 24 → 5 V |
| G1 | блок питания 24 V, ≥ 150 Вт |
| M1 | насос FG-025 (24 V, 0,25 л/мин, 70 бар), штатная плата не используется |
| YA1 | клапан сброса JT22-02, NC, 80 бар, 220 В |
| SP1 | реле низкого давления на входе насоса |
| BK1 | DS18B20 на головке насоса |
| SB1 | кнопка «Стоп / Сброс» |
| — | 4 форсунки 0,08 мм, трубка 1/4" и 1/8", манометр, предохранительный клапан 75–78 бар |
| — | осмос 100 GPD с баком 1,5 л |

## Установка

1. Скопируйте `firmware/secrets.example.yaml` в `secrets.yaml` рядом с прошивкой и заполните.
2. В `firmware/fog-controller.yaml`, блок `substitutions`:
   - `ha_humidity` — entity ID датчика влажности в HA;
   - `timezone` — ваш часовой пояс;
   - `pwm_max` — оставьте 45 до калибровки.
3. Прошейте плату (ESPHome 2026.x, фреймворк ESP-IDF). После первой прошивки главный выключатель автоматики выключен — насос сам не запустится.
4. Добавьте устройство в HA (интеграция ESPHome, ключ `api_key`) и в его параметрах включите «Разрешить устройству выполнять действия Home Assistant» — иначе плата не получит значение датчика влажности.
5. Пройдите калибровку по [разделу 7 ТЗ](docs/TZ.md#7-пусконаладка-и-испытания): мощность ШИМ подбирается по манометру до 65–70 бар, затем `pwm_max` = найденное + 10 %.

## Карточка для Home Assistant

Нужны модули из HACS: **Mushroom**, **mini-graph-card**, **Vertical Stack In Card**, **card-mod**.

Дашборд → «Изменить» → «Добавить карточку» → «Вручную» → вставьте [`homeassistant/fog-card.yaml`](homeassistant/fog-card.yaml). Если устройство привязано к зоне, к entity ID добавится её имя (например, `spalnia_`) — замените префикс в карточке поиском.
