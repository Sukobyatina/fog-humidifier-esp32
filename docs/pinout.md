# Распиновка YD-ESP32-S3 N16R8

Всё, что припаяно, сидит на левом разъёме J1. Интерактивная схема распайки — [онлайн](https://sukobyatina.github.io/fog-humidifier-esp32/wiring.html).

| Вывод | Разъём | Назначение | Статус |
| --- | --- | --- | --- |
| IO5 | J1-5 | A2 XY-MOS, ШИМ насоса | задействован |
| IO7 | J1-7 | A4 SSR, клапан сброса JT22-02 | задействован |
| IO15 | J1-8 | SP1, реле низкого давления | задействован |
| IO18 | J1-11 | BK1, DS18B20 (4,7 кОм к 3,3 V) | задействован |
| IO12 | J1-18 | SB1, кнопка «Стоп / Сброс» | задействован |
| IO48 | на плате | встроенный RGB-светодиод WS2812 | задействован |
| 5V | J1-21 | A5 LM2596S OUT+ (5,0–5,1 V) | питание |
| GND | J1-22 | A5 OUT−, общий минус | питание |
| 3V3 | J1-1 | подтяжки, DS18B20 | питание |
| IO4 | J1-4 | датчик давления BP1 (АЦП) | резерв |
| IO8 | J1-12 | шина I²C, SDA | резерв |
| IO9 | J1-15 | шина I²C, SCL | резерв |
| IO6, IO10, IO11, IO13, IO14, IO16, IO17 | J1 | — | свободны |
| IO1, IO2 | J3-4, J3-5 | — | свободны, АЦП |
| IO21, IO38, IO39, IO40, IO41, IO42 | J3 | — | свободны |

## Не использовать

| Вывод | Причина |
| --- | --- |
| IO0, IO3, IO45, IO46 | strapping-пины, влияют на загрузку |
| IO19, IO20 | USB D− / D+ |
| IO26–IO32 | флэш-память |
| IO35, IO36, IO37 | октальная PSRAM модуля N16R8 |
| IO43, IO44 | UART0: лог и прошивка |
| IO47 | по ТЗ не используется |

## Особенности платы YD-ESP32-S3

- Светодиод WS2812 на GPIO48. Если не загорается — на части плат нужно замкнуть перемычку «RGB» возле светодиода.
- Площадку IN-OUT у вывода 5V не замыкать: диод развязывает USB и внешние 5 V от LM2596S.
